A few especially important facts to keep straight for the exam:

RSA: public ={e,n}, private ={d,n}

Diffie-Hellman: security → discrete logarithm problem

RSA: security → factoring

OAEP: randomized RSA padding

DES: 16 rounds, 56-bit effective key, 64-bit block

AES: 128-bit block, 128/192/256-bit keys → 10/12/14 rounds

ECB: identical plaintext blocks → identical ciphertext blocks

CBC: requires an IV and has limited error propagation

CTR: parallelizable and supports random access

XTS-AES: designed for storage encryption

BBS: PRNG based on factoring difficulty

TRNG: physical entropy; PRNG: deterministic from a seed

SAC: flipping one input bit changes each output bit with probability 1/2

CRT: reconstructs a value from congruences with pairwise-coprime moduli
